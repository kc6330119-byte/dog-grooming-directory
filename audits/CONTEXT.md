## Per-page-type: original vs. sourced

**Groomer listing (indexable, 3,794)**
- Sourced (third party): name, address, phone, hours, rating, review count, photo, map link, lat/long.
- Original to this site: the description body (Phase 1 fact-composition, or Phase 2
  website-derived — **machine-composed, see Finding 1**), the curated internal
  "Grooming Guides" links, the category/type classification, the quality decision itself.

**Groomer listing (stub, 1,522)** — nothing original. Renders only a name and the sentence
*"This dog groomer listing is being reviewed for accuracy before it appears in the public directory."*

**City hub** — sourced: the listing rows. Original: selection/threshold logic only. No templated intro
(deliberately removed after a prior doorway finding).

**State hub** — original: a long hand-written editorial description per state in `config.US_STATES`
(median 1,324 words rendered). Sourced: the listing rows.

**Category** — original: editorial copy (median 3,768 words). Sourced: the filtered rows.
Filter data is only 11–17% populated.

## Technical baseline

- **Sitemap**: 2,873 URLs — 2,724 groomer + 99 state/city + 36 blog + 6 category + 8 static.
  (Live sitemap is 3,963; this build's number differs because the live one was generated
  post-Phase-2 on Netlify. Both exclude stubs.)
- **robots.txt**: generated by build. **Not modified in this audit.**
- **Canonical**: `base.html` emits self-referential canonical from `request_path`; `.html`,
  trailing-slash, www and http variants all 301 to the extensionless canonical (verified live).
- **Structured data**: `LocalBusiness` JSON-LD assembled in Python (`groomer_localbusiness_jsonld`),
  no `aggregateRating` (deliberate — scraped-rating schema is a manual-action risk).
- **Ad units**: `ADSENSE_ENABLED=false`. **0 pages contain `adsbygoogle`.** Rubric G is
  vacuously Pass; P1's ad-ratio clauses cannot be violated today.

## Protocol assumptions that do not match this site

1. **No Three.js/GSAP homepage hero exists.** Verified: no `three.js`, no `gsap`, no `<canvas>`
   on the live homepage. That POC was deliberately deferred and never built. Rubric I's
   LCP-of-hero item is inapplicable.
2. **Ads are entirely disabled**, so "more ads than content" (P1) is not currently possible.
3. **Phase 2 shipped hours before this audit** — 2,695 listings received machine-composed
   descriptions sourced from each business's own website. Per the operator's explicit
   decision, it stays live and is graded as a standing finding rather than reverted.
